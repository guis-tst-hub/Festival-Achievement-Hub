# 校园节日成就站（本地原型）

这是校园节日扫码成就系统的第一版可运行原型。访客页面采用手机比例；电脑测试时会在右侧显示二维码测试台。管理台当前用于验证成就、分类和活动包流程。

## 当前功能

- 访问二维码链接或上传二维码图片解锁成就
- 成就进度仅保存在当前浏览器的 `localStorage`
- 非当前活动的二维码会提示“不是今夜的暗号”
- 管理台可新增、启用或停用成就，并管理分类
- ZIP 活动包结构检查、模板下载和模拟发布
- 活动开放/关闭状态切换

## 本地运行

需要 Node.js `>=22.13.0`。

```bash
npm install
npm run dev
```

打开：

- 访客页面：<http://127.0.0.1:3000/>
- 管理台：<http://127.0.0.1:3000/admin>

电脑端可直接上传二维码图片，或输入测试识别码 `ghost-room-8f32`。测试进度可在二维码测试台中清空。

## 活动包格式

活动包必须是 ZIP，根目录至少包含：

```text
manifest.json
index.html
assets/
```

`manifest.json` 示例：

```json
{
  "eventId": "halloween-2026",
  "name": "万圣夜巡",
  "version": "0.1.0",
  "entry": "index.html"
}
```

管理台的“活动包”页面可以下载完整模板。

## 验证命令

```bash
npm run build
npm test
npm run lint
```

## 当前边界

这仍是本地交互原型：没有管理员登录、服务器数据库、真正的活动包发布和 Docker 配置。浏览器数据不跨设备同步，清理浏览器数据后会丢失。下一阶段应将管理数据、账号和活动包迁移到学校内网服务器，同时继续让学生端成就记录保留在本地。
